# EcoTech Solutions — Web de contacte
Web acadèmica en català d'EcoTech Solutions S.L., una botiga en línia de tecnologia sostenible per a pimes.

## Activar el xat de HubSpot
1. Editeu `config.js`: poseu el número del compte a `HUBSPOT_PORTAL_ID` i el correu del grup a `CONTACT_EMAIL`.
2. A HubSpot, configureu el xat (Chatflow) perquè es mostri en l'URL pública i arribi a la mateixa Inbox que el correu.
3. Comproveu el xat des d'una finestra d'incògnit i dins de l'horari configurat.
4. Eviteu posar dades personals privades o contrasenyes al repositori públic.

## Publicació
A GitHub: Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
Alternativa: descarregueu els arxius i pugeu-los a Netlify Drop.

**Nota per a l'activitat:** La professora demana una landing page creada dins de HubSpot. Aquesta web externa no substitueix automàticament aquella prova ni les captures de la Inbox.
